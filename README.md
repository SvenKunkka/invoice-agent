# 票夹 · 淘宝 / 京东本地取票工具

[English](README.en.md)

为个人淘宝、京东账号代公司采购的场景开发：统一订单、专票优先、申请预览、商家消息草稿、原始发票下载归档、月度 CSV 清单。

## 打开

双击 `start.command`，浏览器会打开 <http://127.0.0.1:8847>。运行环境为 macOS、Python 3.13、uv、Google Chrome，以及首次构建界面所需的 Node.js 和 npm。工具仅监听本机地址。在启动终端按 Control+C 可停止服务。端口冲突时可设置 `INVOICE_AGENT_PORT`。

页面直接进入真实工作区。以 `INVOICE_AGENT_PREVIEW_ONLY=1` 启动时，可以核对订单并生成申请预览，真实提交和申请入口暂停。

## 开始使用

1. 在“设置”填写公司全称、税号、专票资质及收票邮箱。普票备选默认关闭，仅明确不支持专票时可用。
2. 在“设置”分别打开淘宝、京东登录窗口，由本人扫码、完成验证。工具使用专属的 Chrome 资料目录。
3. 选择日期范围和扫描页数。扫描只读官方网页，并报告覆盖情况。可在平台核对年份筛选，也可导入 CSV 或 JSON。
4. 默认工作列表、月报金额及 CSV 只包含已确认且未排除的公司采购。全部导入、待核对和已排除可分别查看。填写排除理由后，重复采集会保留排除。解除排除需要在详情保存。申请前请核对交易状态、发票状态及票种证据。票种未知时先询问专票，退款订单转人工核对。
5. “核对申请”显示订单、金额、票种、公司名与税号。开启真实提交后，工具会再次核对平台页面并执行一次申请。提交结果不明确时，需要在详情记录官方核对依据才能恢复。
6. 已开公司票先确认购买方及税号，再下载原文件。仓库保留 SHA-256、订单关联和原始格式，报销页按月导出 CSV。

## 当前能力与实测边界

| 范围 | 实现情况 |
|---|---|
| 本地订单台账、搜索筛选、企业资料 | 已实现，企业资料和订单载荷本地加密 |
| 专票优先、未知不降普票、退款隔离 | 已实现，规则测试覆盖 |
| 申请预览、单次提交、变更失效、中断恢复 | 已实现，持久提交记录保护 |
| 淘宝 / 京东浏览器适配 | 支持历史筛选、分页读取和覆盖记录。详情读取会核对订单身份。真实申请和下载仍需逐平台验收 |
| 商家沟通及催票 | 自动生成草稿和复制，用户核对后自行发送；没有自动发送或自动解读商家回复 |
| PDF / OFD / XML 下载 | 浏览器下载事件及格式校验、原文件归档、文件指纹查重 |
| 发票验真 / OCR / 票面金额识别 | 未接入。仓库金额来自订单，文件内容及税务真实性未核验；文件查重不等同于发票号码或重复报销核验 |
| 自动巡检 / 后台定时催票 / 月度 XLSX | 当前手动触发扫描和草稿，导出 CSV；未创建系统后台任务 |
| 集中合并开票 | 不承诺个人京东账号支持企业集中开票。当前逐单处理；拆合单、部分退款需人工核对 |

当前版本使用确定性规则。票种依据、实时平台页面可用性和真实申请需要分别验证。

## 本地数据

真实数据默认位于 `~/Library/Application Support/InvoiceAgent/live/`。备份时需同时保存 `invoice-agent.sqlite3`、`encryption.key` 和 `invoices/` 中的原文件。独立登录态保存在 `live/browser-profile/`，其中包含可访问账号的会话数据。目录权限为 700，数据库、密钥和归档文件权限为 600。

可通过环境变量 `INVOICE_AGENT_DATA` 指定新数据根目录。现有原文件不移动、不覆盖。工具不上传订单、公司资料或文件，不调用私有平台接口，不绕过验证码或登录验证。

读取失败时，工具可在 `live/diagnostics/` 留下最多 1 MiB 的本地页面结构记录，供适配页面使用。记录去除脚本、隐藏区域、表单值和非订单类链接参数，但可包含页面可见的订单信息；不会自动上传，也不加入源代码库。任务记录会显示诊断文件位置。

## 订单导入

界面可下载 CSV 模板。JSON 可为订单数组或 `{"orders":[...]}`，必填字段为 `platform`、`order_no`、`product`、`shop`、`amount_fen` 和 `paid_at`。金额用整数分，订单号用字符串，日期格式为 `YYYY-MM-DD`。`paid_at` 表示用于月度汇总的订单日期。最多导入 5000 笔或 3 MiB，重复订单会跳过。

按实际交易填写状态。`special_status` 为 `yes`、`no` 或 `unknown`，证据写在 `evidence`。平台详情链接使用对应平台的官方 HTTPS 地址。

## 开发与验证

```sh
uv sync --locked --python 3.13
uv run pytest -q
cd web
npm ci --ignore-scripts
npm run build
```

依赖锁定于 `uv.lock` 和 `web/package-lock.json`。浏览器适配测试使用固定 HTML 与离线页面；未登录真实账号的测试不证明平台可用。来源与设计依据见 [平台与技术资料](docs/sources.md)。
